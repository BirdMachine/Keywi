## 🎛️ 03 // ADVANCED SOUND REACTOR

<img src="https://raw.githubusercontent.com/BirdMachine/Scratch/non-euclidean-geocities/furniture/30-rack-ears.svg" width="100%">

**IMMINENT:** sound stops being a single global *pick one noise, congratulations* setting.

| ROUTING MODE | PLAN |
|---|---|
| 🎵 **Playlist** | select one or more built-in/custom sounds; play in order, loop, or randomize |
| 🔤 **By action** | separate assignments for letters, numbers, emoji, Unicode, Shift, Enter, tools, etc. |
| 🧭 **By touch position** | assign sound by center / side / corner swipe position |
| ⌨️ **Per key** | specific tap/swipe exceptions can override broader sound rules |

Multi-file selection and assignment are being designed as something closer to a tiny sample rack than a sad settings dropdown.

<img src="https://raw.githubusercontent.com/BirdMachine/Scratch/non-euclidean-geocities/furniture/32-content-feet.svg" width="100%">

## 🧩 04 // BOARD REACTOR

| SOCKET | STATE | NEXT MUTATION |
|---|---|---|
| 🩵 **ALPHA / NUMBER** | LIVE | cleaner board management + customization |
| 💗 **EMOJI** | LIVE / EVOLVING | richer browsing and user-controlled board placement |
| 💛 **UNICODE** | IMMINENT | useful glyph libraries + transformations without leaving the keyboard |
| 💚 **CUSTOM** | ACTIVE | user-created/reordered boards and page behavior |
| `(ﾉ◕ヮ◕)ﾉ*:･ﾟ✧` **KAOMOJI** | IMMINENT | searchable library in the advanced-input/tool layer rather than pretending it is just another square alpha board |

The important distinction now: **boards are boards; tools are tools.** Kaomoji search, formatting and other advanced input utilities belong in the toolbar/tool layer even when they ultimately insert text.

## 🧠 06 // CONTEXT + INPUT BEHAVIOR

**IMMINENT / INFRASTRUCTURE IN PROGRESS**

Keywi should be able to behave differently depending on *where* and *what* you're typing rather than applying one universal decision everywhere.

That includes richer field-aware behavior, **Enter vs Send** controls, context-sensitive tool availability and eventually rules that can make the keyboard adapt without making the user rebuild their layout for every app.

## 🥝 11 // WHY THIS EXISTS

Keywi is still a personal, enthusiast-built fork rather than an attempt to manufacture **A Big Product™**.

It's here because keyboards are an absurdly intimate piece of software and it seems silly that the thing between your thumbs and nearly every conversation you have should be visually boring, behaviorally rigid, or afraid of Unicode.

> **Vibecoded?** Yep. Deliberately iterated? Also yep.
