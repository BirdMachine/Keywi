# 🧬 WHAT ACTUALLY MUTATED HERE

<table>
<tr>
<td width="72%" valign="top">

### 🗺️ Visual key remapping
A friendlier visual editor for changing what keys do, including swipe positions and Keywi's newer input modes.

### 🧩 Custom keyboard boards
Build and manage your own board layouts rather than being limited to the stock keyboard rooms. Board management now has a focused library, templates, creation flow and visual key editing.

### ↔️ Multi-board paging
Custom boards can live alongside the normal keyboard rooms and be paged through from the keyboard instead of requiring a settings expedition every time.

### `(ﾉ◕ヮ◕)ﾉ*:･ﾟ✧` Kaomoji mode
Kaomoji is now an actual live keyboard mode, including the **Emoji ↔ Kaomoji** keyboard cycle, library/search UI and support in the visual/advanced remappers.

### 🧠 Context-aware input infrastructure
Keywi has an input-context layer for field-aware behavior rather than assuming every text box wants exactly the same thing.

### ↵ Smart Enter
More deliberate **Enter vs Send** behavior, including editor-aware handling instead of one universal action everywhere.

## 🖼️ ACTION OVERLAYS // YOUR KEYBOARD CAN REACT NOW

<table>
<tr>
<td width="26%" align="center"><img src="https://raw.githubusercontent.com/BirdMachine/Scratch/non-euclidean-geocities/furniture/03-aquarium-window.svg" width="100%"></td>
<td width="74%">

Keywi can render **GIF/PNG typing overlays** in response to keyboard actions — little visual reactions that happen while you type.

- choose image/GIF media
- preserve transparent PNG rendering
- trigger effects from keyboard actions
- tune the trigger cooldown / rate limit so fast typing doesn't become a tiny denial-of-service attack on your own keyboard

The overlay system is deliberately separate from the persistent keyboard theme: one is the room, the other is the thing that just flew through it.

</td>
</tr>

# 🎨 THEME MATRIX // THINGS YOU CAN MAKE PRETTY

<img src="https://raw.githubusercontent.com/BirdMachine/Scratch/non-euclidean-geocities/furniture/01-optical-bench.svg" width="100%">

Keywi's **Advanced Look & Feel** treats the keyboard as several independently editable surfaces instead of one monolithic theme.

| SURFACE | WHAT YOU CAN CHANGE |
|---|---|
| 🌌 **Main keyboard backdrop** | none / solid / gradient / image / animated GIF · opacity · custom media · saved gradients · gradient angle & stops |
| 🛸 **Suggestion toolbar backdrop** | its own surface independent from the keyboard · solid / gradient / image / GIF · opacity · toolbar border color & width |
| 🍬 **Suggestion lozenges** | independent pill surface · transparent / solid / gradient · independent border styling & colors |
| ⌨️ **Key faces** | key surface style · solid / gradient / transparent treatments · key colors / gradients |
| ✨ **Key borders** | independent border styles including chromatic / metallic-ish treatments rather than inheriting the key face |
| 🔤 **Typography** | custom keyboard font handling and text appearance controls |
| 🫧 **Suggestion motion** | suggestion animation / motion style instead of suggestions merely materializing like tax forms |
| ↕️ **Toolbar geometry** | toolbar-to-keyboard gap plus border width, letting the suggestion area visually detach or dock into the board |
| 🌈 **Gradient library** | reusable named custom gradients with editable angle and color stops, shared across themeable surfaces |
| 🖼️ **Action overlays** | GIF/PNG reaction media and trigger cooldown — transient decoration rather than a persistent surface |

# ⌨️ INPUT LAB // BOARDS, GLYPHS & OTHER CRIMES

<table>
<tr>
<td width="24%" align="center"><img src="https://raw.githubusercontent.com/BirdMachine/Scratch/non-euclidean-geocities/furniture/11-cartridge.svg" width="100%"></td>
<td width="76%">

### 🧩 Board library & templates
Create custom keyboard rooms from a more focused board-management screen, choose a starting template, then edit the actual key grid visually.

### 🧭 Swipe-aware key editing
The visual editor exposes directional assignments in an actual square layout, including the intentionally blank/null center position where appropriate.

### 🧪 Input palette host
Infrastructure now exists for richer keyboard-accessible palettes and tools rather than cramming every future input feature into the same old suggestion row.

### 🔎 Search capture
Palette search can capture keyboard input directly, supporting searchable libraries without bouncing into a separate app.

### 🔤 Compose / combo processing
Keywi has combo-processing infrastructure for multi-character / composed input rather than treating every action as a single literal character.

## 🔮 NEXT MUTATIONS

The current architecture is increasingly less “Thumb-Key with extra colors” and more a set of composable keyboard subsystems. The obvious places to keep abusing this are **Formatting / Fancy Text**, richer Unicode tools, stickers/media, more context-driven behavior, and deeper toolbar/input-palette tools.

Temporal personalities stay deliberately mismatched: **CRT crawls / meter twitches / glass drifts / photon commits / heart beats / mascot remains raster and smug.** Nothing performs synchronized banner aerobics.
