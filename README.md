# 🥝 KEYWI

**🌈 A violently chromatic keyboard mutated for me 🩷✨**

Choose a gem cut, tune your theme, build a board, and make the keyboard yours.

An Android keyboard for swipe typing, custom key actions, and an unreasonable amount of color. A personal fork of [Thumb-Key](https://github.com/dessalines/thumb-key).

## Make yourself at home ✨

1. Open the latest release above and download **Keywi-latest.apk** from **Assets**.
2. Install it, open Keywi, and follow the setup flow to enable and select your keyboard.
3. Choose a **gem cut** for the key arrangement, a **character layout** for what you type, and a **theme** for how it looks. The [getting-started guide](docs/guide/README.md#start-here) walks through setup.

Gem cuts, character layouts, and themes are separate choices. Customize your boards and key actions, then tune colors, gradients, backgrounds, fonts, and feedback to taste.

The handbook includes dated screenshots and source checkpoints; see [screenshot notes](docs/guide/screenshots.md) when comparing it with a newer build. **Keywi** is the release app; **Keywi-dev** builds are for integration testing.
