# Layers and Gem Cuts

Layering is deliberately downstream of the Theme / Facet / Layout split.

A layer is alternate content/action state projected onto the same facet geometry. Machine Cut may expose desktop-like Shift/Ctrl/Alt/Fn layers while ME-Like may expose its own layer transitions; both should use shared semantic layer concepts without forcing identical structural controls.

This keeps the current work compatible with future layering without making generalized layering a prerequisite for the first Machine Cut renderer.
