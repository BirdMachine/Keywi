# Machine Cut scope

Machine Cut is not 'QWERTY mode'. It is a facet: dense desktop-like geometry with rows and power-user controls. QWERTY is merely the first layout used to make that geometry legible.

Future Dvorak/Colemak-style mappings can target the same facet without creating new facets. Conversely, a split or columnar geometry would be a new facet even if it used the same QWERTY mapping.
