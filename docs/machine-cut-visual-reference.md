# Machine Cut visual reference

Machine Cut takes interaction inspiration from Hacker's Keyboard rather than copying it pixel-for-pixel.

Initial topology:

```text
Esc  1 2 3 4 5 6 7 8 9 0 - =  Backspace
Tab  Q W E R T Y U I O P [ ]  \
Ctrl  A S D F G H J K L ; '   Enter
Shift Z X C V B N M , . / Nav Shift
Esc Sys Alt Meta     Space     Fn Sys Left Down Right
```

This is a topology sketch, not the final mapping. The important pressure test is that this facet is row/density oriented and has no ME-Like 3×3 surface, while still consuming Keywi's same Theme and eventual Layer machinery.
