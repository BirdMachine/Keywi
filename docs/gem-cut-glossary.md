# Gem Cut glossary

**Gem Cut** — Keywi's umbrella system for interchangeable keyboard geometries.

**Theme** — appearance; geometry-independent.

**Facet** — complete keyboard geometry/topology.

**Layout** — symbols/actions assigned within a facet.

**Layer** — alternate assignments on the same facet/geometry.

**ME-Like** — existing MessageEase-inspired Keywi facet, including its persistent controls and central swappable 3×3 surface.

**Machine Cut** — dense desktop/power-user facet inspired by Hacker's Keyboard.
