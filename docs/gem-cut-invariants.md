# Gem Cut invariants

- Theme never decides where a key lives.
- Facet never decides what color a key is.
- Layout never silently changes the facet topology.
- Layer changes assignments, not geometry.
- ME-Like's 3×3 center is not a universal abstraction.
- Existing users default to ME-Like.
- Machine Cut must reuse shared appearance/effect primitives rather than fork them.
